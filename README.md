### Midterm Examination Reflection

1. **What is Git used for?** Git is used for version control of files when coding. It helps in saving your progress locally so that you can easily go back, edit, and record.
2. **What is the difference between Git and GitHub?** Git is a tool used to track changes you make on your code files _locally._ On the other hand, Github is a cloud platform where you can create repositories to upload the code files you're working on, as well as record the changes from Git online.
3. **Why is branching useful?** Branching is especially useful when working with a team or working on different features. It allows you to add and modify code files in a 'branch', while your 'main' remains untouched. It ensures that your main is always a workable version of your system, which you can add features or fixes onto from your 'branches' when you are ready.
4. **What command did you use to upload your local commits to GitHub?** I used the command git remote add origin <repository-url> to upload my local commits on Github. This command simply recognizes the link of the online repository I made, and once done, I can upload all my files onto that specific repo.
5. **What did you learn from this activity?** First, I learned how to prepare my files locally by staging and commits. Next, I learned how to upload my local commits onto an online repository in Github, as well as the importance of using branches aside from main. Overall, I learned how to properly utilize Git and Github together that helps in keeping my work clean, organized, and efficient.
